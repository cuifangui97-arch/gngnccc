## 当前故事

这是架空虚构同人，所有聊天、物料、通话和情侣关系情节都不是对真人私生活的陈述。故事共十段，穿插 emoji 猜题、两条舞蹈视频、生日礼物、随手分享的路景与自拍、宿舍夜宵、《向海少年》reaction、手机壳贴纸等日常。reaction 中两人的心理与私下对话均为同人创作，不是对真人想法的判断。豆瓣整理稿用于把握粉丝视角和外界解读的背景，不把作者推测改写为真人事实。

微信通知点开后从本段第一条新消息开始；苏新皓的剧情回复预填在输入框，点发送才显示后续消息。部分回复可二选一。自由留言只保存在本机，不会触发角色自动回复。其他 App 可自由浏览，不作为主线任务。

这次重写更换了故事版本。旧版剧情进度会在刷新时重新开始；本机自由留言及其他保存项保留。微信“我”页的“重新开始”会清除整个本地进度和留言。

电话列表是虚构文字互动，没有浏览器合成语音按钮或朗读。第二段聊天另有一通短来电：接听后只播放用户提供片段中的“帅帅”声音，不显示视频画面；播放结束自动挂断并继续聊天。挂断也能继续后续消息。
